## 风险与后续建议

- 当前排序依赖页面中的显式 `jslog` 索引。它比 CSS 类名稳定，但仍是内部实现细节。
- 单日三次一致只能证明短时间重复性，不能证明跨天或跨地区长期稳定。
- HTTP 请求和浏览器访问可能受到账号、网络出口、实验时间或服务端实验分组影响。
- 建议后续增加跨日定时采样，并定期执行浏览器渲染对照。
- 在确认页面内嵌数据结构前，不应仅根据 URL slug 推断精确扩展标题。
